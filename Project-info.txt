Stack:
Frontend: Bun.js, RSBuild, React.js, TypeScript, RxJS для построения сложных логичческих цепочек (только там где необходимо),
Lightweight Charts для отрисовки графиков, для UI элементов интерфейса используй библиотку Shadcn https://ui.shadcn.com/docs/components

Этапы разработки:
1. Первый этап - Графики.
  - Реализовать функционал отображения графиков (с OHLC-свечами) вытягивая данные из csv файла. 
  Пример файла: "./XAU-USD_1second_BID_2026-01-01T00-00_2026-10-19T23-59-59.csv".
  - Дизайн должен быть в тено-белых тонах, например как у Vercel.
  - Для построения графиков использовать библиотеку Lightweight Charts https://tradingview.github.io/lightweight-charts/docs.
  Также используй этот документ чтобы ориентироваться в документации lightweight-charts https://tradingview.github.io/lightweight-charts/llms.txt.
  Графики должны быть только с японскими свечами - переключаться на другие способы отображения не планируется.
  График должен занимать всю доступную ширину и высоту экрана кроме сайдбара.
  Сделай восходящие свечи белым цветом с черными границами, а нисходящие свечи сделай черного цвета с черными границами.
  - Сделать смену таймфреймов: 1m, 5m, 15m, 30m, 1H, 4h, 1D, 1W, 1M.
  - Сделай возможность добавления на график элементов рисования, таких как: горизонтальная линия, вертикальная линия, прямоугольник. 
  Должна быть возможность эти элементы редактировать, то есть менять цвета, а также положение на графике, для прямоугольника еще менять его размеры.
  - Структура столбцов в csv файле: Time,Open,High,Low,Close,Volume. Пример: 2026-01-01 23:00:00.000+00:00,4323.698,4323.898,4323.698,4323.898,240
  Time в исходном файле это время всегда по UTC. Volume из исходного файла нам не понадобится - его не надо нигде использовать.
  В исходном csv файле как правило будут данные по секундам, то есть каждая строка это информация о секундной свече. Секундные свечи в
  этом проекте мне не нужны, но мне нужны эти данные по секундам для того чтобы в следующих этапах сделать симуляцию движения цены 
  используя эти 60 секундных срезов внутри одной минутной свечи, учитывай это на будущее!
  - Сделать загрузку csv файла с компьютера. Нужно чтобы при клике на кнопку открывалось модальное окно в котором нужно будет указать 
  тикер для инструмента и выбрать файл с компьютера. Здесь же сделай защиту от других форматов файлов кроме csv и при загрузке csv файла,
  проверяй какая у него структура. Структура должны быть строго Time,Open,High,Low,Close,Volume, тобы не было проблем с парсингом файла и 
  извлечением из него праввильных данных.
  - Сделай так чтобы график загружался сначала по последним ценам, а если юзер будет перематывать назад в прошлое, то порциями подгружай
  данные для графика из файла csv.
  - Сделай слева сайдбар в котором будет отображаться список инструментов. В строке каждого инструмента сделай кнопку редактирования, 
  которая откроет модальное окно где можно поменять тикер инструмента и загрузить новый csv файл с новыми актуальными 
  данными, которыми нужно заменить старые.
  - Сделай чтобы при нажатии на колесико мыши на курсоре над графиком появлялось перекрестие от которого идут горизонтальные и 
  вертикальные линии чтобы показывать цену в этом месте (на вертикальной шкале цены справа графика) и дату с временем (на горизонтальной
  шкале времени внизу графика).

2. Второй этап - Simulation Engine.
  - Реализовать Simulation Engine.
  - Для имитации движения цены используй OHLC секундные свечи из исходно файла. Цену рисуй по цене Close секундной свечи.
  - Сделай кнопку Начать симуляцию в хэдере справа от названия котировки, при клике на которую откроется модальное окно где можно задать настройки для начала сессии симуляции.
  В этом окне должны быть следующие поля: поле для выбора даты и времени начала симуляции, поле для выбора даты и времени конца симуляции и рядом галочку с 
  подписью "до конца доступного графика" (для полей с датой и временем используй календарь из библиотеки shadcn calendar#date-and-time-picker), числовое поле для выбора 
  во сколько раз ускорить время (например число 2 значит в два раза быстрее, число 10 значит в 10 раз быстрее) и внизу окна 2 кнопки: Начать и Отмена. Если юзер нажал Начать 
  то кнопка в хэдере должна стать копкой Остановить симуляцию и справа от нее должно появиться меню управления симуляцией с кнопками: Play/Pause, числовым полем для изменения
  скорости в процессе симуляции.

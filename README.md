# Terminal-demo

Локальный терминал для просмотра исторических OHLC-графиков из CSV, симуляции движения цены и торговли на исторических данных. Торговые сессии и закрытые сделки сохраняются в IndexedDB браузера.

## Запуск

Требуется Bun 1.3.14 или новее. Установите зависимости один раз:

```sh
bun install --frozen-lockfile
```

Для каждого запуска достаточно одной команды:

```sh
bun run dev
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000), нажмите **Добавить инструмент**, укажите тикер и выберите CSV из доступных папок. Интерфейс и сервис чтения файлов входят в этот проект; отдельно устанавливать или запускать сервис не нужно.

Закрытие вкладки оставляет сервис работать. Повторная команда обнаруживает уже запущенный экземпляр этого проекта, выводит его адрес и завершается без создания второго экземпляра. Она не останавливает старый процесс. `Ctrl+C` в терминале первого запуска останавливает сервис и сервер разработки. Если порт занят другим приложением, запуск завершается с понятной ошибкой.

Для запуска собранной версии:

```sh
bun run build
bun run start
```

`bun run preview` — сокращение для `bun run start`. Чтобы перейти с `dev` на собранную версию или обратно, сначала остановите текущий экземпляр через `Ctrl+C`: повторный запуск использует уже работающий режим.

## Папки с CSV

Разрешённые папки задаются в `terminal.config.json`. По умолчанию доступна папка проекта (`"."`). Можно указать несколько существующих папок, включая внешние:

```json
{
  "dataDirectories": [".", "./history", "D:/Market-data"]
}
```

Относительные пути считаются от папки проекта. После изменения настроек перезапустите сервис. В окне выбора видны только разрешённые папки, их подпапки и CSV; содержимое файлов не пересылается из браузера.

По умолчанию приложение занимает порт `3000`, сервер разработки — `3001`. При необходимости задайте перед запуском разные значения переменных окружения `TERMINAL_PORT` и `TERMINAL_DEV_PORT`. Сервис слушает только `127.0.0.1`; API проверяет локальный адрес и источник запроса, операции с данными требуют токен текущего сервиса.

## Формат данных

Расширение файла — `.csv`; разделитель — запятая. Заголовок и порядок столбцов должны точно совпадать:

```csv
Time,Open,High,Low,Close,Volume
2026-01-01 23:00:00.000+00:00,4323.698,4323.898,4323.698,4323.898,240
```

Время задаётся в UTC (`+00:00` или `Z`), строки идут по возрастанию времени без повторов. Проверяются число столбцов, даты и корректность диапазона OHLC. Значения Volume не используются.

При первом подключении локальный сервис полностью читает и проверяет файл порциями по 1 МиБ в отдельном Worker Bun. Из исходных свечей формируются `1m`, `5m`, `15m`, `30m`, `1H`, `4h`, `1D`, `1W`, `1M`. Неделя начинается в понедельник UTC, месяц — в первый календарный день. Пропуски торговой истории остаются пропусками; искусственные свечи не добавляются.

График открывает последние 800 свечей и показывает последние 110. При прокрутке в обе стороны сервис выдаёт страницы по 800 свечей из локального индекса SQLite. В браузере хранится окно максимум из 3200 свечей, дальняя часть выгружается из памяти и при необходимости загружается снова.

Новая страница истории применяется после завершения перетаскивания и остановки инерции. Текущие видимые свечи и масштаб сохраняются; подгрузка не вытесняет свечи, на которые пользователь успел переместиться во время запроса.

## Управление

- Выберите инструмент в левом сайдбаре и таймфрейм над графиком.
- Селект **Часовой пояс** в хэдере меняет отображение времени свечей на шкале, в перекрестии и подписях рисунков. По умолчанию выбран Кишинёв (`Europe/Chisinau`). Доступны часовые пояса IANA, включая UTC; выбор сохраняется в браузере для всех инструментов. Летнее и зимнее время учитываются на дату каждой свечи. Положение графика и рисунков сохраняется при переключении.
- На внутридневных таймфреймах границы суток выбранного часового пояса выделены сплошными серыми линиями толщиной 2 px. После перерыва в торгах линия отмечает первую свечу нового дня. Исходные timestamps и агрегация свечей остаются в UTC; меняется их отображение.
- При смене таймфрейма сохраняется выбранный участок истории. Если весь период не помещается в окно свечей, график остаётся около его середины. Переход к последним ценам выполняется отдельной кнопкой со стрелкой.
- Перетаскивайте график для прокрутки; колёсико меняет масштаб.
- Нажмите колёсико над графиком или кнопку перекрестия, чтобы включить его. Повторное нажатие выключает. Шкалы показывают цену и время в выбранном часовом поясе.
- При включённом перекрестии зажмите левую кнопку на графике и потяните курсор: линейка показывает абсолютное расстояние в пунктах / процентах от начальной цены. Один пункт — минимальная единица цены: при трёх десятичных знаках `4120.684 → 4121.618` даёт `934 п. / 0,0227%`. Отпускание кнопки убирает линейку; `Esc` отменяет жест. Выбранный инструмент рисования сохраняет приоритет перед линейкой.
- Для горизонтальной или вертикальной линии выберите инструмент и нажмите на график. Для прямоугольника укажите два противоположных угла.
- Выберите рисунок, перетащите его или его опорные точки. У прямоугольника точки изменяют размеры. Цвет и удаление доступны на панели выбранного элемента. `Esc` отменяет рисование.
- Для копирования зажмите `Ctrl` и перетащите рисунок левой кнопкой, включая его маркеры: предварительное выделение не требуется. Копия сохраняет все свойства исходника; исходник остаётся на месте. `Esc` отменяет копирование.
- Кнопка со стрелкой возвращает к последним ценам.
- Карандаш в строке инструмента открывает редактирование тикера и замену CSV. Старые данные заменяются только после успешного импорта; ошибка или отмена сохраняют прежний набор.
- Корзина в строке инструмента открывает подтверждение удаления. После подтверждения инструмент, рассчитанная история и рисунки удаляются из приложения; исходный CSV остаётся на диске.

## Симуляция

1. Выберите инструмент и нажмите **Начать симуляцию** справа от тикера.
2. Укажите начало и окончание в UTC через календарь shadcn и поле времени с секундами. Галочка **до конца доступного графика** использует последнюю доступную котировку файла.
3. Задайте положительную скорость: `2` означает две секундные свечи за секунду реального времени, `10` — десять. Укажите **Баланс демосчёта, USD** для новой сессии (по умолчанию `1000`) и нажмите **Начать**.
4. Кнопки **Play/Pause** и поле скорости управляют текущей сессией. Скорость можно менять во время воспроизведения. Время и состояние сессии отображаются рядом.
   Удерживайте **стрелку вправо →**, чтобы временно установить скорость **10000×**. После отпускания клавиши возвращается прежняя скорость. В полях ввода и модальных окнах сочетание не действует; пауза остаётся паузой. При уходе из вкладки или сохранении сессии временное ускорение сбрасывается.
5. **Остановить симуляцию** возвращает обычный исторический график. Завершённая сессия остаётся на последней воспроизведённой цене, пока вы её не остановите. Выбор другого инструмента, удаление инструмента или замена его CSV завершают текущую сессию.
6. **Сохранить и выйти** рядом с остановкой приостанавливает симуляцию и сохраняет её в IndexedDB этого браузера. После сохранения можно закрыть вкладку и локальный сервис. При следующем запуске нажмите **Продолжить сохранённую** в хедере инструмента или **Продолжить** у приостановленной сессии в разделе **Торговые сессии**. Восстановленный график откроется на паузе; нажмите Play для продолжения.

Сохраняются время и скорость воспроизведения, таймфрейм, рисунки, открытые сделки и лимитные ордера со SL/TP, торговые стрелки, баланс, объём и цена пункта. Продолжается та же торговая сессия: её история и начальный баланс не создаются заново. Время, проведённое вне приложения, не двигает рынок вперёд. CSV остаётся на диске; исходный инструмент и его набор данных должны оставаться доступными. Обычная кнопка Pause приостанавливает только текущее воспроизведение: перед закрытием приложения используйте **Сохранить и выйти**, в том числе после повторного продолжения.

Рисунки симуляции принадлежат только текущей сессии: они сохраняются при смене таймфрейма и переходе к истории сессий, очищаются при завершении или остановке симуляции и не переносятся в следующую. Каждая новая симуляция начинается без рисунков. Рисунки обычного исторического графика сохраняются отдельно для инструмента.

Каждая секундная свеча перемещает цену по своему `Close`. Текущая свеча выбранного таймфрейма формируется из уже доступных секундных OHLC; будущие свечи и будущие значения `High`, `Low`, `Close` скрыты. Можно переключать таймфрейм и просматривать прошлое: дата симуляции сохраняется, кнопка перехода к последним ценам возвращает к текущей цене сессии.

Промежутки без котировок пропускаются: после последней доступной секунды перед перерывом воспроизводится первая доступная секунда после него. В скрытой вкладке воспроизведение приостанавливается; при возвращении накопленного скачка цен нет. Ожидание данных и перестроение графика при смене таймфрейма также не накапливают симулированное время.

## Торговля

Торговые кнопки появляются в хэдере во время симуляции. Укажите объём в лотах и цену одного пункта для `0.01` лота, затем нажмите **BUY** или **SELL** для входа по текущей цене симуляции. Цена пункта инструмента задаётся при добавлении или редактировании инструмента; её значение по умолчанию соответствует точности исходных цен.

Последняя корректная цена одного пункта для `0.01` лота сохраняется в браузере отдельно для каждого инструмента и используется при запуске его новых симуляций, в том числе после перезагрузки страницы. Переименование инструмента и замена его CSV сохраняют эту настройку. Значение `1` применяется до первого сохранения для данного инструмента.

Щёлкните правой кнопкой по графику, чтобы выставить лимитный ордер объёмом из хэдера. Ниже текущей цены предлагается **BUY limit**, выше — **SELL limit**. Когда High/Low секундной свечи касается уровня, ордер открывается по указанной цене. Открытые сделки и ожидающие лимитные ордера отображаются в таблице под графиком; крестик закрывает сделку или отменяет ордер.

Двойной щелчок по строке или уровню на графике открывает редактирование цены входа, стоп-лосса и тейк-профита. У открытой сделки цена входа заблокирована. Перетаскивание пунктирного уровня перемещает его; `Ctrl` + перетаскивание от цены входа добавляет стоп-лосс или тейк-профит в зависимости от стороны сделки и направления движения. Пересечения уровней защиты проверяются по High/Low секундной свечи. Если одна свеча касается и стоп-лосса, и тейк-профита, симуляция сначала учитывает стоп-лосс.

При перетаскивании цены ожидающего лимитного ордера его выставленные стоп-лосс и тейк-профит смещаются вместе с ним, сохраняя расстояние до входа. Незаданные уровни не добавляются; отдельное перетаскивание стоп-лосса или тейк-профита меняет только выбранный уровень.

Вход и выход отмечаются поверх свечей иконками `TiArrowUpThick` (зелёная вверх) и `TiArrowDownThick` (красная вниз) из `react-icons/ti`. Острия стрелок указывают на цены входа и выхода; у закрытой сделки они соединяются серой пунктирной линией. История текущей сессии следует за графиком при прокрутке, изменении масштаба и таймфрейма.

Изменение результата считается в пунктах: разница между ценой входа и текущей ценой делится на размер пункта инструмента и умножается на заданную цену пункта с учётом объёма. При завершении симуляции открытые сделки закрываются по последней цене. Ссылка **Торговые сессии** в сайдбаре открывает список сессий; щелчок по сессии открывает её страницу с историей и аналитикой. Удаление сессии удаляет и её журнал.

Баланс над списком ордеров принадлежит текущей сессии и меняется на результат каждой закрытой сделки. Плавающая прибыль открытой позиции не меняет баланс. Начальная сумма и каждое последующее изменение сохраняются в IndexedDB вместе с историей этой сессии; в истории сессии доступны начальный и текущий баланс, а также журнал его изменений. Для прежних сессий, созданных до добавления баланса, эти данные отсутствуют.

На странице сессии три вкладки shadcn:

- **История сделок**: таблицы закрытых сделок и изменений баланса по времени UTC.
- **Summary**: Gross Profit/Loss, итоговый результат, Sharpe Ratio, Profit Factor, Recovery Factor, просадка баланса, частота сделок, среднее время удержания. Переключатель **Balance / Growth** меняет историю баланса в USD на рост в процентах от начальной суммы; ниже находится результат по месяцам и годам.
- **Profit & Loss**: дневные прибыль/убытки и чистый результат, **Money / Deals** для перехода к количеству прибыльных/убыточных сделок, разбивка по дням недели и источникам торговли. Все сделки текущего движка относятся к Manual, включая лимитные ордера и закрытия по S/L или T/P. Графики построены ApexCharts.

Sharpe считается как средний P/L закрытой сделки, делённый на выборочное стандартное отклонение, без годового пересчёта и при нулевой безрисковой ставке. Profit Factor не определён без убыточных сделок, Recovery Factor — без просадки. Максимальная денежная и относительная просадки баланса вычисляются независимо от исторических максимумов баланса. Частота сделок за неделю экстраполируется из фактической длительности симуляции. Equity и загрузка депозита отмечены как недоступные: плавающий результат и маржа в историческом журнале не сохраняются. Для прежних сессий без начального баланса отображается накопленный P/L, а рост и относительная просадка отсутствуют.

Секундные CSV содержат одну ценовую серию OHLC. Поэтому симуляция не моделирует отдельные Bid/Ask, спред, комиссию и проскальзывание; исполнение и плавающий результат рассчитываются по ценам этой серии.

Сервис читает исходный CSV порциями с нужного места. Для быстрого поиска используется небольшой индекс байтовых позиций каждых 4096 записей. Для новых импортов он строится сразу; для ранее подключённых файлов — автоматически при первом запуске симуляции. Подготовка большого файла может занять время: отображается загрузка, её можно остановить кнопкой остановки сессии. В памяти движка находятся не более двух страниц по 800 секундных свечей.

## Хранение и структура

Исходный CSV остаётся на своём месте и не копируется в приложение или IndexedDB. Его секундные данные сохраняются в оригинале для следующих этапов. Локальная база `.data/market.sqlite` хранит путь и параметры файла, список инструментов, рисунки и рассчитанные свечи девяти таймфреймов. Для неё нужно свободное место на диске; при замене временно хранятся старый и новый наборы рассчитанных свечей.

Точность цены (до восьми десятичных знаков) определяется по всем исходным OHLC при импорте и сохраняется для всех таймфреймов. Существующая база обновляется автоматически: для ранее подключённых инструментов точность восстанавливается по минутной истории. Если при её агрегации были утрачены более мелкие разряды исходных цен, подключите CSV заново через редактирование инструмента.

Не перемещайте, не удаляйте и не меняйте подключённый CSV: при обращении к истории сервис проверяет его доступность, размер и время изменения. Обновлённый или перемещённый файл подключайте через редактирование инструмента. При ошибке или отмене замены прежний набор сохраняется. Если импорт прервётся вместе с процессом, незавершённые данные удалятся при следующем запуске.

После перехода с прежней браузерной версии выберите CSV заново. Старая IndexedDB с копиями рыночных свечей не переносится и не удаляется автоматически; актуальная версия использует IndexedDB только для торговых сессий и закрытых сделок. Прежние копии рыночных данных можно удалить через настройки данных сайта в браузере, если они больше не нужны.

- `src/domain` — свечи, валидация входных данных, UTC-агрегация, настройки симуляции и расчёты сделок.
- `src/application` — Simulation Engine, Trading Engine и контракт доступа к рыночным данным.
- `src/infrastructure` — HTTP-клиент локального сервиса, поток прогресса импорта и Dexie-хранилище торговой истории.
- `server` — запуск, защита от повторного запуска, API и выбор разрешённых файлов.
- `server/data` — потоковый разбор CSV через Papa Parse, SQLite, разреженный индекс исходного CSV и постраничное чтение свечей.
- `src/chart` — интеграция Lightweight Charts и готовых инструментов рисования.
- `src/components` и `src/App.tsx` — React-интерфейс и компоненты shadcn/ui.
- `tests` — проверки CSV, агрегации, локального хранилища, API, окна графика и торгового движка.

RxJS не подключён: в первом этапе нет цепочек, которые требуют его использования.
